## Описание проекта

Двумерная аркада: игрок управляет кораблём, стреляет по астероидам и набирает очки.
Реализованы тороидальное поле, инерционное движение, вращение объектов и тайловая
анимация взрывов. Все изображения создаются самим кодом, внешние ресурсы не нужны.

## Функциональные возможности

### Основной функционал

- Заставка; игра начинается только по щелчку внутри её прямоугольника.
- Начальные значения: 3 жизни, 0 очков.
- Неподвижное звёздное небо и полупрозрачный слой астероидов, движущийся влево.
- Поворот, ускорение, торможение без двигателя до полной остановки.
- Два изображения корабля: с работающим двигателем и без него.
- Все движущиеся объекты переходят через противоположные границы поля.
- Случайные позиции, линейные и угловые скорости астероидов.
- Ракеты из носа корабля с постоянной скоростью и ограниченным временем жизни.
- Попадание: удаление ракеты и астероида, взрыв, одно очко.
- Столкновение корабля: удаление астероида, взрыв и неподвижное возрождение в центре.
- При поражении остаются счёт, жизни и заставка; игровые объекты скрыты.
- Астероиды свободно проходят друг сквозь друга.

### Дополнительный функционал

- Проверка столкновений учитывает соседство противоположных краёв поля.
- Частота стрельбы ограничена, пробел можно удерживать.
- Новые астероиды не появляются ближе 150 пикселей к кораблю.
- Копии объектов у краёв делают переход визуально плавным.

## Требования к системе

- Python 3.10–3.13, Windows / macOS / Linux с графическим дисплеем.
- Внешняя библиотека: pygame 2.6.1; версия закреплена в requirements.txt.
- Стандартные библиотеки: math, random, dataclasses; тесты — unittest, os.
- Интернет нужен для установки библиотеки, во время игры не нужен.

## Структура проекта

```text
asteroids/
├── .gitignore
├── README.md
├── requirements.txt
├── settings.py
├── entities.py
├── art.py
├── main.py
└── tests/
    └── test_game.py
```

Основная программа состоит из четырёх файлов, как требует задание:

- settings.py — все настраиваемые параметры с комментариями и единицами.
- entities.py — базовый Body, наследники Ship, Rocket, Asteroid, класс Explosion.
- art.py — создание изображений, тайлового листа и функции отрисовки.
- main.py — класс Game, события, цикл, коллизии и состояния.

Такое разделение отделяет физику от графики. Методы сущностей не открывают окно.
Иерархия: Body → Ship / Rocket / Asteroid. Explosion хранит возраст анимации,
Game управляет объектами, а функции art рисуют их на экране.

## Пример использования

1. Запустите программу: увидите заставку, Lives: 3 и Score: 0.
2. Щёлкните вне заставки: игра не должна начаться.
3. Щёлкните внутри заставки: появится неподвижный корабль в центре.
4. Поверните его, включите двигатель, затем отпустите вверх: скорость уменьшится.
5. Удерживайте пробел; за каждый уничтоженный астероид получите одно очко.
6. После столкновений запас жизней меняется 3 → 2 → 1 → 0.
7. Следующее столкновение при уже нулевом запасе возвращает заставку.
8. Счёт сохраняется на заставке; щелчок по ней начинает новую игру с 3 и 0.

## Физика и соответствие заданию

Направление движения определяется через cos и sin угла. Координаты переносятся
по модулю ширины и высоты; скорости при переносе не меняются. При выключенной тяге
скорость умножается на exp(-DRAG × dt), затем обнуляется ниже порога STOP_SPEED.
Столкновения проверяются по окружностям, а не по точному контуру изображения.

Дальность ракеты: 480 × 0,85 = 408 пикселей, что меньше 650 — короткой стороны окна.
Ракеты не наследуют скорость корабля. Взрыв — горизонтальный спрайт-лист из 12 тайлов;
нужный тайл выбирается по времени жизни и извлекается через subsurface.
Динамический фон — прозрачное изображение, две копии которого прокручиваются влево.

В задании явно сказано завершать игру, если ДО столкновения осталось 0 жизней.
Поэтому начальные 3 жизни дают три возрождения, а четвёртое столкновение — поражение.
На поражении взрывы также скрываются, поскольку заставка не должна рисовать игровые
объекты. Случайные астероиды создаются с периодом 1,1 секунды; попытка появления
слишком близко к кораблю пропускается ради отсутствия мгновенного попадания.

## Проверка качества

```sh
python -m unittest discover -s tests -v
```

Тесты проверяют перенос и сохранение скоростей, коллизии через края, дальность и
срок жизни ракет, остановку корабля, последовательность жизней, очки и взрывы.
Четыре теста физики выполнены успешно. Два графических теста по умолчанию
пропускаются: в среде подготовки инициализация SDL превысила время ожидания.
Для запуска всех тестов на macOS/Linux выполните:

```sh
RUN_GRAPHICS=1 python -m unittest discover -s tests -v
```

Они используют виртуальный дисплей SDL. Визуальный вид и управление нужно
проверить обычным запуском python main.py на своём компьютере.
Вручную проверьте мышь, клавиши, плавность движения и смену изображения двигателя.
Методы и функции документированы; сложные вычисления прокомментированы.
